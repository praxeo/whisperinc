# Read-aloud script, set 2 (written 2026-09-28)

A second test set with an **independent reference**: you read these lines, so the script itself is the ground
truth, and nothing depends on what any transcriber (Scribe included) wrote. Everything here is fictional, and
there are deliberately **no personal names** (your Scribe list holds colleagues' surnames: those stay out of
the repo).

## How to record

- One line = one take. Hold Ctrl+Space, read the line at the pace you normally dictate, release, and give it
  a second before the next one. The passages in C, F are single takes too.
- Any window will do as the target (Notepad is easiest). You don't need to check what pastes. Keep all audio
  is on, so the audio and text land in `%APPDATA%\.WhisperInk\archive\`. The active provider doesn't matter.
- Stumbled? Read the line again. The last attempt of each line is the one that counts. Don't edit anything.
- Read what is written the way you'd say it: "mg" is milligrams, "2.4 ATA" is "two point four A-T-A",
  "over" in a blood pressure is "over". Say hard words the way you naturally say them.
- Only when no patient conversation is audible in the background.
- Each set stands alone; stop after any set. Priority: A, B, C (about 15 minutes), then D to G.

## Extras (optional)

The point is conditions, not new words, so these repeat lines from above.

- **N01 to N10, noise:** read A01 to A10 again at your usual workstation with its normal background noise
  (no patient conversation audible).
- **Q01 to Q05, quiet:** read B01 to B05 again very quietly, as if someone were asleep nearby.
- **X01 to X03, not speech:** three takes with no words: a throat clear, one cough, and a 3-second hold in
  silence. The right answer for each is nothing; anything a model writes is a made-up word.

## How this gets scored (for the next session)

Match each archived take (`archive\yyyy-MM\take-*.json`, in time order, after this set was started) to a line
by order and text similarity, using the **last** attempt of each line, never the best one. Build a manifest
like `ab-corpus\manifest.json` with `reference` = the script line. Where every model disagrees with the script
in the same way, suspect a misread and ask the owner before counting it. Before scoring, extend
`_score_corpus.ps1`'s normalization to fold units and formats (mg / milligrams, cm / centimeters, mmHg,
"60%" / "60 percent", "3.2 by 2.1" / "3.2 x 2.1", "96 over 58" / "96/58"), add self-test cases, and give the
three X takes their own check (any output is a failure). For the B lines run Scribe Medical with all 228
keyterms, with none, and with trimmed lists to see which entries it needs (CLAUDE.md 10.1). Run every
cloud provider with `_scratch\corpus-cloud` after `--dry`. The script is fictional and holds no names, so the
recordings need no more care than the six scripted clips.
